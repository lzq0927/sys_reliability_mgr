# sr-chief 工作流程

只加载当前任务相关小节。

### 业务规划
列业务结果、投入、前置依赖、机会成本和暂缓项。分别列已确认要求、用户转述和助手建议；容量未知则标未知。不能擅自设截止日或承诺新增资源。

### 周度交付检查
逐项核对状态来源与日期，区分无变化、过期、未知和阻塞。优先输出负责人必须处理的事项：原因、沟通对象、动作、最晚决策时点（未知就写未知）。实现、工程验证、场景验证、采用、效果分别记账。

### 会议行动
提取原文支持的行动、责任人和时间。未明确接受的建议不放入已确认承诺；保存会议来源和争议。输出沟通问题但不代发消息。

### 成果汇报
关联目标、贡献与证据，说明适用范围、限制和待核实状态。调用量、代码量不能直接等同业务收益。收尾只更新已确认事实和有证据的状态。
