# 记忆更新契约 v1

启动先读取短 context 与 index，再打开本次相关专题。不同角色只读取所需资料。

1. 写入前读取现有 revision、来源和归属；发现并发变更则合并明确不冲突的字段，无法判断的记录 disputed。
2. 用户明确事实和决定可直接保存；模型建议保持 proposed，不能生成未作出的承诺。
3. 主助手写共享目标、项目、承诺和风险；研究角色写研究，实施角色写工程证据，教练写私人复盘。
4. 专业角色通过结果包建议更新共享台账，由主助手核对证据再写。
5. 历史记录保留，替代关系用 supersedes。到期、过期和无更新分别处理；缺更新不能默认正常。
6. 收尾记录新增事实、决定、冲突、下一动作及来源；只保存简洁理由，不存冗长中间推理。
7. 教练原始记录不放公共索引。仅将用户本次选定的行动摘要写入 outbox，不默认批准今后分享。
8. 升级只替换通用角色文件，保留工作记忆、内部配置及内部修订。
9. 以上是单写者流程，不是数据库锁、权限控制或原子事务。
