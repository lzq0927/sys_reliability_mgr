# 内网适配与单向迁移（包版本 0.1.0）

目标 OpenCode 二进制版本、内部模型与 ReMAP 基线均需在目标环境登记；当前包不预设版本或模型名称，不声称已通过内网验收。
先复用实际 ReMAP 内网开发指南与固定依赖，不替换已有 sd-dfr-remap、生成式任务配置或模型凭据。

## 导入
只导入已审查 kit 和 SHA256SUMS.json；不导入外部聊天、工作记忆、人员资料、workspace.local.json、日志或完整旧 Git 历史。
逐文件验证摘要后，在目标版本支持的目录安装。可选命令：
```sh
python tools/install.py --host opencode --target TARGET --role sr-chief --role sr-research
```
上述命令写 .opencode/skills；若固定版本不支持该目录，按其文档手工复制完整角色目录并实测加载，不改 ReMAP 受控任务目录来碰运气。
安装器只复制文件，不连接网络、不调用模型、不初始化内部数据。旧安装有内部修订会停止，先备份并在内网合并。版本升级保留业务记忆和内部配置。
内部仓库只配置内部 remote，所有内部修补、验收结果及真实数据留在内网。

## 执行等级
A：对话、字段、工具调用及异常恢复均实测稳定后，允许受限单步工具执行。
B：工具不稳定但能生成结构时，仅产草稿；程序校验后人工触发命令。
C：复杂任务不稳定时使用表单、规则和求解器，模型仅辅助短文本。
等级逐角色确定；无法验证工具执行就不能写调用成功。不通过时降级而非放宽权限。

## 验收
在批准的外联阻断环境记录宿主、模型、工具、依赖、数据格式与包版本。
先合成用例 E01—E09，每角色新聊天独立运行两次；再由用户在内网加入真实材料。
验证最小资料权限、加载、新聊天恢复、输入错误、工具失败与记忆保留。实际项目承诺及技术语义由负责人判断。
主助手试用一周，研究/实现走一条真实工作链，教练做一次准备与复盘，记录事实错误、修订时间、净节省时间及行动效果。
不把外部文件检查、合成算例、模型自评或两个助手一致当作内部部署成功。
