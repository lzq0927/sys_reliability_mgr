# 交接契约 v1

任务书字段：taskId、revision、fromRole、toRole、scope、status、工作目录、问题、验收、约束、输入文件及版本/摘要、可改路径、非目标、输出路径、停止条件。

status 使用 draft / ready / running / completed / blocked。只有输入真实存在、版本可追溯、范围明确且关键取舍已由用户确认或在既有授权内，才能标 ready。通用演示不得伪装成真实产品任务。

执行前核对任务 revision、输入摘要、工作树状态和可改目录；不具备输入时完成独立部分，依赖部分返回缺口。

结果包必须对应 taskId 与 revision，包含：
- 完成 / 部分完成 / 阻塞，以及对问题的回答；
- 实际产物路径、代码版本和未提交修改；
- 输入、模型/求解器版本、种子或确定性配置；
- 实际命令、退出结果、测量值与未运行项目；
- 限制、反例、未解决事项、建议更新的业务字段。

可靠性结论区分代码正确、模型成立、参数可信及现实验证。意见一致不算独立验证。
由用户切换角色或显式授权跨聊天交接；不默认发送消息、新建聊天或自主委派。
