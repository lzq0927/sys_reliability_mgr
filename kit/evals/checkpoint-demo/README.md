# 检查点合成实验

用途：演示交接、确定性计算、证据引用与分层状态记录。Python 3.9+ 标准库即可运行，不依赖 ReMAP、网络或模型。

模型为整数时间步。每个正常计算步产生一个正确工作单位；计算满 interval 后保存，保存 cost 步全部结束才持久化。故障优先于当步计算/保存，丢弃未持久化工作并消耗一个恢复步，已保存工作保留。窗口末只计持久化工作。所有数据都是合成的，正确性是显式假设，不是测量结果。

指标为“固定时间窗口内已持久化正确工作单位 / 总时间步”，不是实际训练产品的已确认指标。无随机采样，因此不声称置信区间或现实外推。

在本目录运行：

```sh
python -m unittest -v test_model.py
python run.py --input input.json --output result.json
```

状态审视：代码可运行、已验证时间线与边界、未验证真实参数/静默错误/实际训练终态/产业效果。测试采用手工可追踪时间线。预算不变量为已保存工作＋未保存工作＋丢失工作＋保存开销＋恢复时间＝总窗口。

result.json 是运行产物，不应加入通用发布源。发布前移出本目录，使用新输出目录更方便。
